# Therapist Chatbot

A text-based therapist chatbot developed in C++ that simulates simple conversations through user input and predefined responses. The program recognizes emotion- and topic-related keywords to provide relevant replies and maintains conversational context across interactions.

**Features:**
- **Keyword Recognition:** Match user input against predefined emotion and topic keywords.
- **Predefined Responses:** Generate responses tailored to recognized keywords and conversation scenarios.
- **Conversation Tracking:** Track conversation state and previous answers to support context-aware interactions.
- **Reusable Response Logic:** Use functions to organize response generation and handle different conversational scenarios.

**Technical Highlights:** Uses C++ classes and methods, vectors to store keyword-response associations, conditional logic to determine replies, and state tracking to manage conversational flow.
